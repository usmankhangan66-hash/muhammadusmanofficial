## How to Open Locally

1. Extract the ZIP file to any folder on your computer.
2. Open the folder.
3. Double-click **`index.html`**  
   – It will open in your default browser (Chrome, Edge, Firefox, etc.).
4. No internet connection is required for basic viewing (except Google Fonts if loaded).

Alternatively, you can right-click `index.html` → **Open with** → choose your browser.

## How to Edit

- **Text / content**: Edit `index.html` in any text editor (Notepad, VS Code, etc.).
- **Colors / layout**: Edit `style.css`.
- **Photo**: Replace `assets/profile.jpg` with a new photo (keep the same filename, or update the `src` in `index.html`).
- **Resume**: Replace `assets/resume.pdf` with a new PDF (same filename).

## How to Publish Online (Share Link with Employers)

You can host this free on several services:

### Option 1 – Netlify (easiest)
1. Go to [https://www.netlify.com](https://www.netlify.com) and sign up (free).
2. Drag and drop the entire portfolio folder onto the Netlify dashboard.
3. You will get a link like `https://random-name.netlify.app`.
4. You can change the site name in Site settings.

### Option 2 – GitHub Pages
1. Create a free account at [https://github.com](https://github.com).
2. Create a new repository (e.g. `portfolio`).
3. Upload all files from this folder.
4. Go to **Settings → Pages** → set source to the main branch.
5. Your site will be at `https://yourusername.github.io/portfolio`.

### Option 3 – Vercel
1. Go to [https://vercel.com](https://vercel.com) and sign up.
2. Import the folder or connect a GitHub repo.
3. Deploy – you get a free `*.vercel.app` link.

### Option 4 – Any free hosting
Upload the folder via FTP or file manager to any web host that supports static HTML.

After publishing, share the website link with employers along with your phone number and email.
